Versión escritorio · Windows

Aplicación para portátil

Archivo portátil para Windows que abre con doble clic, sin instalar Python. Permite buscar correos con PDF, seleccionar un mensaje y procesar únicamente sus adjuntos. Las credenciales se guardan localmente y no se incluyen en el programa.

Estado del proyecto

Motor y adaptadores creados. Falta autorizar el correo, elegir la hoja de destino y definir exactamente los datos a extraer a partir de un PDF de ejemplo. La versión web no ejecuta Python en el navegador: el procesamiento ocurre en GitHub Actions.

Para obtener un ejecutable, abra una compilación exitosa en GitHub Actions y descargue el artefacto «DepuradorPDF-Portable-Windows». Los archivos de datos y credenciales no deben guardarse en este repositorio público.
