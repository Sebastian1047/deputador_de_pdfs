Archivo portátil para Windows que abre con doble clic, sin instalar Python. Permite buscar correos con PDF, seleccionar un mensaje y procesar únicamente sus adjuntos. Las credenciales se guardan localmente y no se incluyen en el programa.

Estado del proyecto

Motor y adaptadores creados. Falta autorizar el correo, elegir la hoja de destino y definir exactamente los datos a extraer a partir de un PDF de ejemplo. El navegador accede al servidor interno Python. Falta la instalación por TI y la configuración de Gmail, Sheets y campos reales.

El servidor Python y el panel de operación estarán dentro de la red empresarial. GitHub Pages es únicamente una página informativa; ningún correo o PDF real se muestra aquí.
